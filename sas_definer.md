  # sas_definer

  The sas_definer package provides macros to create a **Define-XML** file
  from an Excel specification.

  ## Macros

  | Macro | Description |
  |-------|-------------|
  | `%spec2xml()` | Wrapper. Runs `%spec2meta()` and then `%definexml()` to create define.xml from an Excel spec. |
  | `%spec2meta()` | Reads the Excel spec and creates the SAS metadata datasets (HEADER, DATASETS, VARIABLES, VALUELEVEL, METHODS, CODES, COMMENTS, DOCUMENTS, ...). VALUELISTOID and ITEMOID are auto-generated. WHERECLAUSEOID is used as is when the sheet has any value, otherwise it is auto-generated. |
  | `%definexml()` | Generates the Define-XML (version 2.0) from the SAS metadata datasets. |
  | `%definexml_attributes_for()` | Provides ATTRIB statements for the input metadata datasets. |
  | `%definexml_quote_xml()` | Escapes XML special characters. |

  A dummy Excel spec is included as additional content (`ADAM_METADATA_dummy.xlsx`).

  `%definexml()` and its helper macros are based on the definexml macros by
  Katja Glass (MIT License, 2016), with modifications.

  ## Implemented

  1. Convert Excel spec of the format in *"Implementing CDISC Using SAS: An End-to-End Guide, Revised Second Edition"* to SAS metadata (`%spec2meta`).
  2. Convert SAS metadata datasets to XML in Define-XML version 2.0 (`%definexml`).
  3. Create define.xml from an Excel spec in one step (`%spec2xml`).
 
  ## Planned (tentative)

  1. Convert SAS metadata datasets to XML in Define-XML version 2.1.
  2. Convert define.xml to Excel spec.
  3. Consistency check macro (undefined or duplicated OIDs, broken references of codelists / methods / comments / leaves, unused definitions, duplicated VALUEORDER).
  4. Output of the WHERE_CLAUSES and ANALYSIS_RESULTS sheets (currently not used by `%definexml`).
  5. Support for SDTM (SDTM-IG) Define-XML.
  6. XSD schema validation of the generated Define-XML.
  7. Bundle the Define-XML stylesheet (define2-0-0.xsl).
  8. Better handling of external codelists (MedDRA, WHODrug, etc.).
  9. More tests and samples.

## `%definexml()` macro <a name="definexml-macro-1"></a> ######

### Macro `%definexml()`

Creates a Define-XML file from information datasets (header, datasets, variables,
valuelevel, codes, methods, comments, documents).
Use `%definexml_attributes_for()` to create the input datasets with the expected structure.

Original work: Copyright (c) 2016 Katja Glass (MIT License).

#### Parameters

- `outfile` : output file name (required)
- `indat_header` : general information dataset (default `header`, required)
- `indat_datasets` : datasets information (default `datasets`, required)
- `indat_variables` : variables information (default `variables`, required)
- `indat_valuelevel` : value level information (default `valuelevel`)
- `indat_codes` : code list information (default `codes`)
- `indat_methods` : method information (default `methods`)
- `indat_comment` : comment information (default `comments`)
- `indat_documents` : document information (default `documents`)

#### Example

~~~sas
%definexml(outfile=define.xml);
~~~

## `%definexml_attributes_for()` macro <a name="definexmlattributesfor-macro-2"></a> ######

### Macro `%definexml_attributes_for()`

Generates in-line ATTRIB statements to create the interface datasets used by `%definexml()`.

Original work: Copyright (c) 2016 Katja Glass (MIT License).

#### Parameter

- `data` : one of `header datasets variables valuelevel codes methods comments documents`

#### Example

~~~sas
data header;
  %definexml_attributes_for(header);
  studyname = "12345";
run;
~~~

## `%definexml_quote_xml()` macro <a name="definexmlquotexml-macro-3"></a> ######

### Macro `%definexml_quote_xml()` (internal)

Escapes XML special characters (`& " ' < >`) in all character variables of a WORK dataset.
Used internally by `%definexml()`; not intended to be called directly.

Original work: Copyright (c) 2016 Katja Glass (MIT License).

#### Parameter

- `data` : WORK dataset name to be modified in place

## `%spec2meta()` macro <a name="spec2meta-macro-4"></a> ######

### Macro `%spec2meta()`

Reads a metadata specification Excel file (PHUSE Define-XML template style) and creates
the WORK datasets used as input of `%definexml()`:
`HEADER`, `DATASETS`, `VARIABLES`, `VALUELEVEL`, `METHODS`, `CODES`, `COMMENTS`, `DOCUMENTS`,
plus `WHERE_CLAUSES` and `ANALYSIS_RESULTS` (not in the PHUSE template).

#### Parameter

- `specfile` : full path of the specification Excel file (xlsx) (required)

#### Example

~~~sas
%spec2meta(specfile=C:\path\to\ADAM_METADATA.xlsx);
~~~

## `%spec2xml()` macro <a name="spec2xml-macro-5"></a> ######

### Macro `%spec2xml()`

Creates a Define-XML file directly from a metadata specification Excel file.
It runs `%spec2meta()` to create the metadata datasets in WORK,
and then `%definexml()` to write the Define-XML file.

#### Parameters

- `specfile` : full path of the specification Excel file (xlsx) (required)
- `outfile` : output Define-XML file name (required)

#### Example

~~~sas
%spec2xml(
  specfile=C:\path\to\ADAM_METADATA.xlsx,
  outfile=C:\path\to\define.xml
);
~~~
